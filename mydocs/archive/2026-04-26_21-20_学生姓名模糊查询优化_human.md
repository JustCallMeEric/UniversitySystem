## 需求摘要

对已有的 `GET /api/students/search` 接口进行两项优化：
1. **姓名参数必填**：未录入时返回明确提示 `请输入学生姓名`
2. **返回学院名称**：查询结果中新增 `collegeName` 字段，学院匹配失败时显示 `该学院不存在`

---

## 实现概要

| 层级 | 文件 | 变更 |
|---|---|---|
| 异常处理 | `GlobalExceptionHandler.java` | 新增 `IllegalArgumentException` handler，统一返回 HTTP 400 |
| Controller | `StudentController.java` | `searchByName` 增加 `trim()` + 非空校验 |
| DAO/XML | `StudentMapper.xml` | `selectByNameContaining` 改为 `LEFT JOIN college`，扩展查询字段 |
| Service | `StudentServiceImpl.java` | `findByNameContaining` 遍历结果，填充默认学院名 |

---

## 关键决策

| # | 问题 | 决策 |
|---|---|---|
| 1 | 校验方式：Spring 注解 vs 手动校验 | 手动校验 + `IllegalArgumentException`，更直观、不引入额外注解依赖 |
| 2 | trim 位置 | Controller 层统一 trim，Service 层信任入参 |
| 3 | 学院名称查询方式 | SQL 层 `LEFT JOIN`（与 `selectByStudentId` 模式对齐），非 Service 层循环查询 |
| 4 | 默认文案 | `该学院不存在`（用户指定），与 `findByStudentId` 的 `未查询到该学院` 区分 |

---

## 验收方式

```bash
# 正常查询（返回 collegeName）
GET /api/students/search?name=张

# 空参数（返回 400）
GET /api/students/search?name=

# 无 name 参数（Spring 默认返回 400）
GET /api/students/search
```
