# Archive: 学生姓名模糊查询 (LLM Reference)

## 接口契约

| 层 | 方法签名 |
|---|---|
| Controller | `@GetMapping("/search") ResponseEntity<List<Student>> searchByName(@RequestParam String name)` |
| Service | `List<Student> findByNameContaining(String name)` |
| DAO | `List<Student> selectByNameContaining(@Param("name") String name)` |

## SQL 映射

```xml
<select id="selectByNameContaining" resultMap="StudentResultMap">
    SELECT student_id, name, age
    FROM student
    WHERE name LIKE CONCAT('%', #{name}, '%')
    ORDER BY id
</select>
```

## 约束条件

- 无分页
- 中文姓名，不涉及大小写敏感问题
- 无结果返回空 list（非 404）
