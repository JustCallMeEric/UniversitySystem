## 关键代码模式

### 1. Controller 手动参数校验

**位置**: `StudentController.java:56-63`

```java
@GetMapping("/search")
public ResponseEntity<List<Student>> searchByName(@RequestParam String name) {
    if (name == null || name.trim().isEmpty()) {
        throw new IllegalArgumentException("请输入学生姓名");
    }
    List<Student> students = studentService.findByNameContaining(name.trim());
    return ResponseEntity.ok(students);
}
```

**复用场景**: `@RequestParam` 参数必填校验，不想引入 `@Validated` + `@NotBlank` 时可用此模式。

### 2. 统一异常处理（IllegalArgumentException → 400）

**位置**: `GlobalExceptionHandler.java:46-53`

```java
@ExceptionHandler(IllegalArgumentException.class)
public ResponseEntity<Map<String, Object>> handleIllegalArgument(IllegalArgumentException ex) {
    Map<String, Object> response = new HashMap<>();
    response.put("error", "Validation failed");
    response.put("message", ex.getMessage());
    response.put("timestamp", LocalDateTime.now().toString());
    return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(response);
}
```

**复用场景**: 受控业务异常统一返回标准化 400 响应。

### 3. MyBatis 模糊查询 + LEFT JOIN

**位置**: `StudentMapper.xml:42-48`

```xml
<select id="selectByNameContaining" resultMap="StudentResultMap">
    SELECT s.id, s.student_id, s.name, s.age, s.college, s.created_at, s.updated_at, c.name AS college_name
    FROM student s
    LEFT JOIN college c ON s.college = c.id
    WHERE s.name LIKE CONCAT('%', #{name}, '%')
    ORDER BY s.id
</select>
```

**注意**: 排序字段指定表别名（`s.id`），避免多表 JOIN 时列名歧义。

### 4. Service 层默认值填充

**位置**: `StudentServiceImpl.java:74-83`

```java
@Override
public List<Student> findByNameContaining(String name) {
    List<Student> students = studentMapper.selectByNameContaining(name);
    for (Student student : students) {
        if (student.getCollegeName() == null) {
            student.setCollegeName("该学院不存在");
        }
    }
    return students;
}
```

**复用场景**: 关联数据为 null 时需要显示友好文案的场景。
