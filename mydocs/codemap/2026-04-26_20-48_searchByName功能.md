## 各层关键代码

### 1. Controller 层

**文件**: `src/main/java/com/university/controller/StudentController.java:56-60`

```java
@GetMapping("/search")
public ResponseEntity<List<Student>> searchByName(@RequestParam String name) {
    List<Student> students = studentService.findByNameContaining(name);
    return ResponseEntity.ok(students);
}
```

- 接收 `name` 请求参数（必填，无默认值）
- 直接透传 Service，无业务逻辑处理
- 返回 `200 OK` + `List<Student>` JSON

### 2. Service 层

**接口**: `src/main/java/com/university/service/StudentService.java:17`

```java
List<Student> findByNameContaining(String name);
```

**实现**: `src/main/java/com/university/service/impl/StudentServiceImpl.java:74-77`

```java
@Override
public List<Student> findByNameContaining(String name) {
    return studentMapper.selectByNameContaining(name);
}
```

- 纯透传，无额外校验或后处理
- 未处理 `null` / 空字符串场景（透传至 SQL 层）
- 未关联查询 college 名称（与 `selectByStudentId` 不同）

### 3. DAO 层

**接口**: `src/main/java/com/university/dao/StudentMapper.java:20`

```java
List<Student> selectByNameContaining(@Param("name") String name);
```

### 4. SQL 层

**文件**: `src/main/resources/mapper/StudentMapper.xml:42-47`

```xml
<select id="selectByNameContaining" resultMap="StudentResultMap">
    SELECT student_id, name, age
    FROM student
    WHERE name LIKE CONCAT('%', #{name}, '%')
    ORDER BY id
</select>
```

- 模糊匹配：`%keyword%`
- 返回字段：`student_id`, `name`, `age`（**注意**：未返回 `id`, `college`, `created_at`, `updated_at`）
- 排序：按 `id` 升序
- 使用 `CONCAT` 函数拼接通配符，存在潜在数据库兼容性差异（H2/MySQL 均支持）

## 返回字段映射

```
SQL 列                Student 属性
─────────────────────────────────────
student_id     →      studentId
name           →      name
age            →      age
(college_name) →      collegeName   (SQL中无此列，但 resultMap 包含映射)
```

由于 `resultMap` 中定义了 `college_name` → `collegeName` 的映射，但本 SQL 未查询该列，因此返回对象中 `collegeName` 为 `null`。

## 风险点

| 风险 | 位置 | 说明 |
|------|------|------|
| SQL 注入 | SQL | 使用 `#{}` 预编译参数，**已防护** |
| 空参数查询 | Controller | `name` 为空字符串时，SQL 条件变为 `LIKE '%%'`，返回全表数据 |
| 全表扫描 | SQL | `LIKE '%xxx%'` 无法利用索引，大数据量时性能下降 |
| 缺失字段 | SQL | 未返回 `id`, `college`, `created_at`, `updated_at`，前端可能依赖 |
| N+1 问题 | 无 | 单次查询，无关联对象循环加载 |

---

## 索引建议

如 `name` 字段查询频率高，可考虑：
- MySQL 5.7+: `FULLTEXT INDEX` + `MATCH ... AGAINST`
- 或引入搜索引擎（Elasticsearch）做姓名检索
