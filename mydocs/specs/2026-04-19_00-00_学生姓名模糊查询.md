## 3. Research Findings (研究成果)

### 3.1 现有代码结构

| 层级 | 文件 | 现状 |
|---|---|---|
| Controller | `StudentController.java` | 现有 `/api/students` 端点，支持 `GET /`（全量）、`GET /{studentId}`（精确） |
| Service | `StudentService.java` / `StudentServiceImpl.java` | 提供 `findAll()`、`findByStudentId(String)` 方法 |
| DAO | `StudentMapper.java` | 提供 `selectAll()`、`selectByStudentId(@Param)` |
| Mapper XML | `StudentMapper.xml` | 现有 SQL 映射，使用 LEFT JOIN 查询学院名称 |
| Entity | `Student.java` | 包含 `id`, `studentId`, `name`, `age`, `college`, `createdAt`, `updatedAt`, `collegeName` |

### 3.2 需求理解

- **功能**：全模糊查询（LIKE '%keyword%'）
- **输入**：学生姓名关键字
- **输出**：学生ID(`studentId`)、姓名(`name`)、年龄(`age`)
- **无需**：学院信息（需求文档未要求）

### 3.3 涉及文件（预估）

1. `StudentMapper.java` — 新增 `selectByNameContaining(@Param("name") String name)` 方法
2. `StudentMapper.xml` — 新增 `<select id="selectByNameContaining">` SQL（LIKE 查询）
3. `StudentService.java` — 新增 `findByNameContaining(String name)` 方法
4. `StudentServiceImpl.java` — 实现 `findByNameContaining()`
5. `StudentController.java` — 新增 `GET /search?name={name}` 端点
