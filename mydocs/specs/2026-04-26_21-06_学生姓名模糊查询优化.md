## 1. Requirements (Context)

- **Goal**: 增强已有模糊查询接口，增加必填校验与学院名称返回
- **In-Scope**:
  - `GET /api/students/search?name={keyword}` 的姓名参数必填校验（trim 后非空）
  - 校验失败返回 HTTP 400 + 提示 `请输入学生姓名`
  - 查询结果中 `collegeName` 字段需填充真实学院名称
  - 学院匹配失败时 `collegeName` 显示 `该学院不存在`
  - 模糊查询行为保持不变（`LIKE '%keyword%'`）
- **Out-of-Scope**:
  - 分页
  - 其他字段变更
  - 接口路径变更
  - 引入新的依赖或框架

## 2. Research Findings

### 2.1 现有代码结构

| 层级 | 文件 | 现状 |
|---|---|---|
| Controller | `StudentController.java` | `GET /api/students/search` 直接透传 `name` 参数，无校验 |
| Service | `StudentServiceImpl.java` | `findByNameContaining` 纯透传 Mapper，无后处理 |
| DAO/XML | `StudentMapper.xml` | `selectByNameContaining` 仅查询 `student_id, name, age`，无学院关联 |
| Exception | `GlobalExceptionHandler.java` | 已处理 `StudentNotFoundException` (404)、`MethodArgumentNotValidException` (400)、通用 `Exception` (500)；**未处理 `IllegalArgumentException`** |

### 2.2 方案分析

| 方案 | 说明 | 评估 |
|---|---|---|
| A: Controller 手动校验 + 抛异常 | `if (name.trim().isEmpty()) throw new IllegalArgumentException("请输入学生姓名")` | 简单直接，不依赖 `@Validated`，与现有架构兼容 |
| B: `@Validated` + `@NotBlank` | Controller 类加 `@Validated`，参数加 `@NotBlank` | 需新增 `ConstraintViolationException` handler，改动面更大 |

**决策**: 采用方案 A（手动校验 + `IllegalArgumentException`），理由：
- 逻辑直观，代码可读性强
- 不需要引入额外的 Spring 校验注解依赖
- 只需在 `GlobalExceptionHandler` 中新增一个 handler 即可统一处理

### 2.3 SQL 调整分析

参考 `selectByStudentId` 的 LEFT JOIN 模式，将 `selectByNameContaining` 的 SQL 扩展为：
```sql
SELECT s.id, s.student_id, s.name, s.age, s.college, s.created_at, s.updated_at, c.name AS college_name
FROM student s
LEFT JOIN college c ON s.college = c.id
WHERE s.name LIKE CONCAT('%', #{name}, '%')
ORDER BY s.id
```

- 使用 `LEFT JOIN` 确保无学院的学生也能返回
- 返回完整字段，保证 `resultMap` 完整映射
- 排序字段从 `id` 改为 `s.id`，避免歧义

### 2.4 默认学院名处理

Service 层遍历查询结果，对 `collegeName == null` 的记录设置 `该学院不存在`：
```java
for (Student student : students) {
    if (student.getCollegeName() == null) {
        student.setCollegeName("该学院不存在");
    }
}
```

1. `GlobalExceptionHandler.java` — 新增 `IllegalArgumentException` handler
2. `StudentController.java` — `searchByName` 方法加 trim + 非空校验
3. `StudentMapper.xml` — `selectByNameContaining` SQL 改为 LEFT JOIN + 扩展字段
